English installation and usage: README.md
中文安装与使用说明：README.zh-CN.md
Contributions / 参与贡献：CONTRIBUTING.md

Requires Python 3.11 or later. Install dependencies before launching:
需要 Python 3.11 或更新版本，启动前请先安装依赖：

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt
    .venv\Scripts\python run.py --open

Windows: after setup, double-click Start.cmd. Stop.cmd stops the background app.
Windows 完成安装后可双击 Start.cmd；用 Stop.cmd 停止后台应用。

Default address / 默认地址：http://127.0.0.1:8765/
In-app bilingual guide / 应用内双语指南：http://127.0.0.1:8765/guide

Keep the private data/ directory when upgrading. Do not upload it to GitHub.
升级时保留私人 data/ 目录，不要把它上传到 GitHub。
