简体中文

在个人中心配置研究领域、来源与计划、AI 连接。填写研究提示词，检查 AI 理解后的实际研究范围，再应用或启动历史检索。界面和摘要语言可分别选择。

搜索与作者身份

OpenAlex 使用标题和摘要向量召回候选；Crossref、arXiv 提供补充文本检索。AI 根据摘要中的问题、方法、对象和排除条件进行判断，并保留原文依据。没有摘要时不声称已读全文，主题相关性保留为不确定。OpenAlex 每条语义描述最多 50 篇，检索覆盖及错误会显示。

以作者为中心时，AI 提取姓名和机构，系统核对 OpenAlex 身份并显示可用 ORCID，再按作者标识检索、逐条检查署名。机构用于消歧，也包含其早期机构的成果。未指定主题时不增加学科限制，不启用仅限奠基论文的筛选。旧检索可复制后重新理解；原结果和检查点保留。

任务、额度与 IF

每日更新、历史检索及期刊指标查询可并行运行，共享 1–64 个 AI 请求，最多 16 项独立任务。模型及推理档位修改后适用于同一连接下尚未发出的请求；已完成结果不重做。每日 AI 请求数设为 0 表示应用内不限，服务商额度和费用仍适用。中断后按已保存进度恢复；手动暂停需手动继续，网络问题退避重试，每日额度暂停在次日或调高额度后重试。

新期刊及旧论文缺失的 IF 自动排队查询。AI 联网搜索或读取程序取得的出版方公开页面，只有两年 JIF、指标年份、来源与原文证据通过核验后才保存。无法核验时保持缺失，无需导入数据集。论文详情允许手动更正。

资料与运行

今日按相关性排序；资料库的搜索、收藏筛选和作者／期刊等排序立即生效。删除进入独立回收站，可恢复。个人中心的数据管理支持清空全部研究数据，必须输入 CLEAR ALL、停止运行任务并成功自动备份；保留研究配置、AI 连接及用量，暂停每日采集。

数据库位于 data/academicupdater.sqlite3，时间戳备份位于 data/backups。凭据单独由 Windows 用户加密保存在 credentials.dpapi，数据库导出不含凭据。升级前停止应用并备份 data，替换源码时保留 data。恢复时先停止应用、保留原目录副本，再用备份替换数据库。不要让两个实例共用一个数据库。

可启用 Windows 登录自启。电脑需唤醒并联网，启动时会补查当天遗漏更新。关闭浏览器不停止后台应用，使用 Stop.cmd 停止。ChatGPT 登录资格与单独计费的 API 不同，应用不会自动切换到付费 API。

English

Personal profile contains Research field, Sources & schedule and AI connection. Describe your intent, review the AI interpretation and apply it or start a historical search. Interface and summary languages are independent.

Discovery and author identities

OpenAlex retrieves candidates with title/abstract embeddings; Crossref and arXiv add complementary text retrieval. AI assesses the research problem, method, target and exclusions against available abstracts with grounded quotations. Missing abstracts mean uncertain topical relevance, not full-text reading. OpenAlex semantic retrieval allows up to 50 candidates per description; source caps and errors remain visible.

Author requests resolve the name, institution and optional ORCID to an OpenAlex identity, retrieve by author ID and validate each authorship. Institution disambiguates the person without excluding earlier career papers. Unspecified topics stay unrestricted and do not use the landmark-only filter. Copy and reinterpret old searches to adopt the new strategy; old results and checkpoints remain saved.

Tasks, budgets and journal IF

Daily updates, histories and metric lookups can overlap, sharing 1–64 AI requests across up to 16 jobs. Model and reasoning changes apply to unsent requests within the same connection; completed results remain intact. Daily AI limit 0 means no application cap, while provider quotas and charges still apply. Restart recovers saved progress; manual pauses require Resume. Temporary network errors retry with backoff, and daily-budget pauses retry after local midnight or a budget increase.

New journals and old records missing IF enter the automatic lookup queue. AI uses native web search or public publisher pages fetched by the app. Two-year JIF, metric year, source and exact evidence must pass verification. Unsupported values stay missing; no dataset import is required. Manual correction remains available in paper details.

Data and operation

Today ranks by relevance. Library filters and author/journal sorting apply immediately. Deletions go to a separate restorable Trash. Profile data management can clear research data only after typed CLEAR ALL confirmation, inactive jobs and a successful backup. Settings, AI credentials and usage accounting remain, and daily collection is paused.

The database is data/academicupdater.sqlite3; uniquely timestamped backups are in data/backups. Windows-encrypted credentials are separate in credentials.dpapi and excluded from database exports. Before upgrading, stop the app and back up data, then replace code while preserving data. Stop before restoring and keep a copy of the original folder. Never share one database between running instances.

Optional Windows login startup launches in the background. The computer must be awake and online; startup checks for missed updates that day. Closing the browser does not stop the application; use Stop.cmd. ChatGPT sign-in eligibility differs from separately billed API access; there is no silent paid-API fallback.
