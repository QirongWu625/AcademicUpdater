# AcademicUpdater identity / 标识设计

The mark combines an open book with an upward arrow in its negative space. The small amber dot represents a newly discovered update. Forest green and warm amber match the application's quiet reading interface.

展开的书页与负形中的向上箭头结合，琥珀色圆点代表新发现的更新。深绿与暖琥珀色沿用应用的阅读界面。

- Asset / 图像：[`static/logo.png`](../static/logo.png), transparent PNG.
- Use / 使用位置：application header, browser icon, English/Chinese README.
- Created with the built-in image generation tool; no separate image API credential was used.
- 应用标题栏、浏览器图标及双语 README 使用同一标识；由内置图像生成工具制作。

Generation prompt:

> Use case: logo-brand. Create a polished original app icon for AcademicUpdater, a personal scholarly discovery and research history application. One isolated compact symbol, no words or letters: an open book with two clean angular pages subtly forming an upward update arrow, with a small circular discovery dot at the upper right. Confident simple geometric silhouette, flat vector-like design, readable at favicon size. Deep forest green (#173F36) primary and warm amber (#C78B37) small accent; visual personality scholarly, calm, precise. Square canvas with generous equal margins, front-facing, no mockup, no shadows, no gradients, no decorative particles, no border, no watermark. Transparent background, only the mark.

The screenshots under `docs/images/` show the real application running against an isolated, synthetic dataset. Example titles, authors, citation counts and assessments are illustrative, not real publications or measured AI performance. No personal library or connected account is shown.

`docs/images/` 为真实应用在隔离虚构数据集下的截图。示例标题、作者、引用数及分析用于展示功能，不是真实文献或 AI 性能测评，不包含个人资料库或已连接账号。
